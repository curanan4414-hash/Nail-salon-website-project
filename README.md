# ทำเล็บ เอาสังคม

เว็บไซต์สำหรับจองคิวร้านทำเล็บใกล้มหาวิทยาลัยพะเยา

ระบบช่วยให้ลูกค้าสามารถดูบริการ เลือกวันและเวลา
จองคิว ตรวจสอบสถานะ เลื่อนนัด และยกเลิกการจองได้
โดยไม่ต้องสมัครสมาชิก

## เทคโนโลยีที่ใช้

HTML + CSS + JavaScript

## เปิดใน VS Code

เปิดโฟลเดอร์โปรเจกต์ใน VS Code

จากนั้นเปิดไฟล์ `index.html` ผ่าน Browser

## การใช้งานระบบ

- ลูกค้าไม่ต้องสมัครสมาชิก
- เลือกบริการทำเล็บ
- เลือกวันและเวลาที่ต้องการ
- กรอกชื่อและเบอร์โทรศัพท์
- ชำระเงินมัดจำ 50 บาท
- ตรวจสอบสถานะการจอง
- เลื่อนนัดได้ 1 ครั้ง
- ยกเลิกการจองได้
- ระบบออกหมายเลขการจองสำหรับตรวจสอบคิว

## ระบบมัดจำ

- มัดจำ 50 บาท
- ระบบล็อกคิวไว้ 15 นาที
- หากไม่ส่งหลักฐานการชำระเงินภายในเวลาที่กำหนด
  คิวจะถูกปล่อยอัตโนมัติ
- เงินมัดจำไม่สามารถขอคืนได้เมื่อยกเลิกคิว

## การเลื่อนนัด

- สามารถเลื่อนนัดได้ 1 ครั้ง
- ต้องแจ้งล่วงหน้าอย่างน้อย 2 ชั่วโมง
- หากมาสายเกิน 10–15 นาที อาจถูกยึดเงินมัดจำ

## หน้าหลักของระบบ

- หน้าหลัก
- บริการและราคา
- จองคิว
- ตรวจสอบสถานะ
- เลื่อน/ยกเลิกการจอง
- ระบบสำหรับเจ้าของร้าน

## ระบบสำหรับเจ้าของร้าน

เจ้าของร้านสามารถ

- ดูรายการจอง
- ตรวจสอบสลิป
- ยืนยันการจอง
- เปลี่ยนสถานะการจอง
- จัดการบริการ
- จัดการคิวลูกค้า
